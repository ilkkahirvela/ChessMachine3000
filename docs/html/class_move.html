Detailed Description

Represents a chess move.

The Move class encapsulates a chess move, including the starting and ending coordinates, as well as an optional promotion piece. It provides constructors to create moves with or without promotion and a utility method to convert the move into a human-readable string.

string Move::toString ( ) const

Returns a string representation of the move.

Converts the move to a human-readable string using standard chess notation. For example, a move from e2 to e4 would be represented as "e2e4". If the move involves pawn promotion, the promotion piece is appended.
