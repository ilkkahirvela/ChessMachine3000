Detailed Description

Main program for chess with human vs bot and bot vs bot game modes.

At startup, the user selects the game mode:

  • Human vs Bot: The human chooses a color and plays against the bot.
  • Bot vs Bot: Both sides are controlled by bots.

The program uses iterative deepening minimax search with alpha-beta pruning.

Entry point for ChessMachine3000.

Presents a settings menu where the user selects game mode (Human vs Bot or Bot vs Bot), side (White/Black), bot think time, and whether to display legal moves. After configuration the game loop runs until checkmate, stalemate, or a draw condition (50-move rule or threefold repetition) is reached, then returns to the menu.
